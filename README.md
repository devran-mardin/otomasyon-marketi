# Otomasyon Market

## Amaç
Otomasyon Market projesi.
Yapmış olduğum yapay zeka otomasyonlarını burada satışa çıkarmak: WhatsApp, Instagram, Telegram, Signal, Facebook, TikTok gibi yapay zeka otomasyonları.
## Stack
- Python / HTML / JS

## Kurulum ve Çalıştırma
```bash
# Gerekli bağımlılıkları yükleyin
pip install -r requirements.txt
```
